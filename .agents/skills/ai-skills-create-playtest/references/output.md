# Playtest output

Use this compact format:

```text
Open the application: <verified URL>

Playtest: <focused question>

1. <setup/action>
   Expected: <observable result>
2. <action>
   Expected: <observable result>

Pass when: <criteria>
If it fails, report: actual result, reproduction steps, visible console/error text, and a screenshot or recording when useful.
```

Use exact labels and locations from the application when known. Mark optional exploratory checks separately from required checks. Include timing, layout, state transitions, persistence, audio, or visual details only when relevant to the target.
